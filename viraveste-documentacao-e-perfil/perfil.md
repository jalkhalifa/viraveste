# Jamila Khalifa

**Desenvolvedora web · Ciência, filosofia e tecnologia**

Crio sites, portfólios e catálogos digitais para profissionais e pequenos negócios. Meu trabalho parte de uma pergunta: como transformar uma necessidade real em uma experiência simples de usar?

## O que orienta meu trabalho

- Compreender o objetivo do projeto e as necessidades de quem vai utilizá-lo.
- Organizar o conteúdo para facilitar a navegação e o contato.
- Criar interfaces responsivas, com uma identidade visual coerente.
- Explorar interações que contribuam para a experiência.

> Criar começa por questionar: olhar de outro modo para o que existe abre espaço para o que pode existir.
